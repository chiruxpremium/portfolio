## Files

- `index.html`: the complete website, including CSS and JavaScript.
- `resume.pdf`: the supplied résumé, used by both Download Resume links.

## Deploy to the existing GitHub Pages site

1. Extract this ZIP.
2. Open https://github.com/chiruxpremium/portfolio and select **Add file → Upload files**.
3. Upload `index.html`, `resume.pdf`, and `README.md` directly to the repository root. Replace the existing HTML and README, then commit to `main`.
4. GitHub Pages will rebuild using the repository's existing deployment configuration. Check the **Actions** tab for completion.
5. Visit https://chiruxpremium.github.io/portfolio/ and refresh after the deployment finishes.

Keep `index.html` and `resume.pdf` in the same directory. Do not upload the ZIP itself as the website.

## Local preview

Open `index.html` in a browser, or run `python -m http.server 8000` in this folder and visit http://localhost:8000.
